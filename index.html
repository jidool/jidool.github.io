고르지 않은 발달, 파악할 수 없는 현장. 교사는 빠르게 파악해야 하지만 수십 명을 동시에 돌보는 현실에서는 불가능하다.

자세히 · 배경, 다섯 가지 판단, 결과, 한계

배경

  • Bloom: 인간 지적 발달의 약 50%가 만 4세 이전에 완성된다. 이 시기에 놓친 지연은 학령기까지 누적된다
  • 국가 발달 선별도구 K-DST는 부모 응답 기반이라 교사가 직접 활용하기 어렵다
  • 보건복지부 2023 아동종합실태조사: 취약 환경 아동일수록 발달 점수가 전반적으로 낮다
  • 연구 질문: 데이터로 영유아 발달 패턴을 유형화하고, 각 유형에 필요한 교육적 접근을 제안할 수 있는가

전처리 흐름

2,150명 → 1,770명(Denver II 유효) → 1,018명(K-DST 유효) → 973명(3+5차 결합). 역코딩 규칙(1→2 정상 / 2→1 주의 / 3→0 지연 / 4→NaN), 전 문항 무응답 380명 제거, StandardScaler 정규화

내가 내린 판단

  1. 데이터 병합 배제: 수집 시점·방법·대상 아동이 달라 독립 모듈로 배치해 상호 보완
  2. 결측의 정보적 해석: 전 문항 무응답 380명(17.7%)은 검사 시행 기준에 따른 구조적 결측
  3. K=3 채택: Silhouette 최고값은 K=2였지만 현장 활용성과 Elbow 완만 지점을 근거로
  4. AUC 0.996 재해석: K-Means 라벨을 같은 특성으로 학습해 과대추정이 불가피하므로 군집 경계 선명도 지표로 규정
  5. 이론 기반 가중치: 언어 30%(Bloom) · 인지 25%(K-DST) · 사회성 25%(Vygotsky ZPD) · 소근육 20%

결과

  • 정상 529명(54.4%) · 경계선 236명(24.3%) · 지연의심 208명(21.4%), 4유형으로 세분화
  • 발달은 인지-언어(45.8%)와 운동-사회성(29.1%) 두 독립 축으로 진행
  • 언어 변수 단독으로 분류의 절반 이상 설명(Feature Importance 0.580), ARI 0.40 → 연속 스펙트럼으로 해석
  • 환경변수 통합 시 발달점수 92.9% vs 환경 7.1%, 가구소득이 가장 강한 환경 예측 변수
  • 파이프라인: 기술통계 → 상관분석 → PCA → K-Means → 계층적 클러스터링 → Random Forest → NLP(TTR·MLU). 과제 범위(8단계)를 넘어 유형 세분화와 환경변수 통합까지 확장

산출물: 교사용 진단 웹앱

  • 전체 대시보드: KPI 4개 · 군집 분포 · 유형 도넛 · 위험도 히스토그램 · 성별 비교
  • 교사용 진단 도구: Denver II·K-DST 슬라이더 입력 → 즉시 위험도 게이지
  • 아동 개별 조회: 군집·유형·위험도 필터, Claude API로 개입 방향 문장 생성(미연결 시 대체 텍스트)

자세히 · 배경, 변수 정의, 5단계 설계

배경

  • 2022년 서울청년패널 기초분석: 서울 청년 34.7%가 우울 증상 의심, 그중 16.7%가 고위험군
  • 한 달 중 3주 이상 집 밖에 나가지 않은 물리적 고립 청년 3.4%
  • 현행 정책은 이미 은둔한 청년의 발굴·상담에 초점. 사후 회복에서 사전 예방으로의 전환 근거 제시가 목표

변수

  • 독립변수, 사회 관계망 지수: ① 관계 만족도 ② 지지망 지수(7개 상황별 도움 가능 여부) ③ 관계 인식 지수(나·타인·사회, 4점 척도)
  • 종속변수: 은둔 정도(사회적 단절의 정도와 지속성)

누적 5단계 설계

  1. 기술통계 및 전처리: 변수의 변별력 선행 점검
  2. 이분형 로지스틱 회귀: 유의하지 않으면 설계 재수립
  3. Cox 비례위험 생존분석: 전이 위험 배수와 개입 골든타임, 우측 절단 처리
  4. Random Forest + SHAP: 비선형·상호작용, 개인 수준 기여도
  5. 층화 5겹 교차검증: 은둔 진입자 2.4% 불균형, AU-PRC·F1·C-index와 부트스트래핑 95% 신뢰구간

주제

예비교사가 설계하는 미래형 교수·학습 모델: AI를 통합한 수업 모델과 교수·학습 지도안

제안

고등 선택과목 <매체 의사소통>을 재구성하고, AI 통합 수업 모델 ‘BASS 모형’과 단원 지도안을 설계

핵심 내용

  • 배경: 2022 개정 교육과정의 디지털 역량 강조와 ‘매체’ 영역 신설. 현행 매체 교육과 디지털 네이티브 학습자의 실제 사이의 괴리
  • BASS 모형: 백워드 설계(영속적 이해·성취 목표 재설정) + ASSURE(AI 도구 선정 매뉴얼) + SAMR(수정·재정의 수준의 AI 통합)
  • 대단원 지도안 → 1단원 차시별 지도안 → 시연 차시 세부 지도안 → 차시별 학습지까지 작성
  • AI 활용 정도·SAMR 수준·자기평가 루브릭으로 모델 적합성을 스스로 평가

  • 기능: 사진·위치·음성 신고와 AI 촬영 가이드, 처리 결과 인증·실시간 안내, 참여 포인트 보상, 위험 지도·사전 경고·정책 제언
  • 기술 구상: 신고 텍스트 NLP 분류, YOLO 기반 CV 분석, GIS·환경 데이터와 멀티모달 심각도 계산, 위험 히트맵
  • B2G SaaS 수익 모델과 용산구 시범 → 전국 확산 단계별 시행 계획, 기대효과 수치화
  • 앞선 대회의 낙선 원인(결과물의 구체성 부족)을 분석해 방향을 다시 잡은 재도전
